#+title: 人生管理配置 - 使用说明
#+startup: overview

* 说明
本配置通过 =lisp/org-life.el= 管理人生目录中的主体、事件、规划和任务。
=init.el= 加载该模块，=lisp/org-mode.el= 设置中文 TODO 状态。

* 文件与目录
| 文件或目录               | 作用                                                                             |
|--------------------------+----------------------------------------------------------------------------------|
| =early-init.el=            | 在 Windows Emacs 31.1 上关闭原生编译代码加载和即时编译，以规避该环境的启动问题。 |
| =init.el=                  | 将 =lisp/= 加入加载路径，按顺序加载各模块，并保存 Emacs Custom 设置。              |
| =lisp/packages.el=         | 配置 GNU ELPA 和 MELPA，初始化包管理器，加载 =use-package= 并启用自动安装。        |
| =lisp/fonts.el=            | 设置霞鹜文楷等宽字体、字号和 UTF-8 编码。                                        |
| =lisp/display.el=          | 启用内置浅色主题，设置文本宽度、视觉换行和窗口位置，处理 Windows 临时路径。      |
| =lisp/completion.el=       | 启用 Eldoc 参数提示，以及 Corfu 自动补全和候选项循环。                           |
| =lisp/org-mode.el=         | 设置中文 TODO 状态、状态日志和 Org 文档样式。                                    |
| =lisp/org-life.el=         | 提供人生目录的事件、规划、任务、议程和回收区命令。                               |
| =.gitignore=               | 排除已安装的包、缓存、历史记录和 Emacs 自动生成文件。                            |

| =elpa/=                    | Emacs 下载的软件包及索引；不由 Git 跟踪。                                        |
| =auto-save-list/=、=url/= 等 | Emacs 运行时产生的自动保存记录或缓存；按需生成。                                 |

模块加载顺序为包管理、字体、显示、补全、Org 配置和人生管理。

* 明暗主题
- 默认使用内置明亮主题 =modus-operandi=；按 =C-c t= 或执行 =M-x config-toggle-theme= 切换到暗色的 =modus-vivendi=，再次执行可切回。
- Org 标题、代码块、表格、链接和 TODO 状态会随切换调整颜色。切换只影响当前 Emacs 会话；重启后默认恢复明亮主题。
- 如需更改启动主题，可在加载 =display= 模块之前设置 =config-default-theme= 为 =modus-operandi= 或 =modus-vivendi=。

* 启用
1. 确保 =init.el= 加载 =org-life= ，并已将 =lisp/= 加入 =load-path= 。
2. 人生目录默认为 =~/人生/= ；如需修改，可自定义变量 =life-root= 。
3. 重新启动 Emacs，执行 =M-x life-open-root= 或按 =C-c l r= 检查根目录入口。
4. 在测试副本中熟悉新建和删除操作，再用于正式数据。

| C-c l p   | life-new-plan       | 新建规划并登记         |

| C-c l d p | life-delete-plan    | 删除规划并移入回收区   |

| C-c l d c | life-empty-trash    | 永久清空回收区         |

* 新建与登记
- 主体目录位于 =个人/P编号/= 或 =组织/O编号/= ，并须包含 =目录.org= 。
- 新建事件或规划时，先选择主体或事件作为直接父容器，再输入名称。
- 父容器的 =目录.org= 必须有一级标题 =* 登记= ，以及对应的二级标题 =** 事件= 或 =** 规划= 和登记表。
- 登记表的名称列为普通文字，目录列显示相对目录并链接到入口文件。例如：
  #+begin_example
  | E-0001 | 事件名称 | [[file:事件/E-0001/目录.org][事件/E-0001]] | 2026-11-23 | 未启 |
  | P-0001 | 规划名称 | [[file:规划/P-0001/规划.org][规划/P-0001]] | 2026-11-23 | 未启 |
  #+end_example
- 任务写入所选事件的 =任务/任务.org= ，状态使用 Org TODO 标题管理。

* 编号与状态
- 事件和规划分别在所属主体范围内编号；不同主体可以使用相同编号。
- 任务在直接所属事件内编号。编号从当前已存在目录或任务标题中计算；删除最高编号后，该编号可能被再次使用。
- 在父容器 =目录.org= 的事件或规划登记行按 =C-c l s=，再按 =t=、=i=、=p=、=d= 或 =c=，分别设为未启、进行、暂停、完成或终止；修改后保存文件。
- 登记状态与任务 TODO 标题的状态不会自动同步。
- 刷新议程会用扫描到的事件任务文件替换 =org-agenda-files= 。

* 删除与回收区
- 删除事件或规划时，选择对象并确认；整个目录移入 =~/人生/.life-trash/= ，同时移除直接父容器登记。事件下的子事件、规划、任务和其他内容都会一同移入。
- 删除任务时，在正式事件的 =任务/任务.org= 中将光标放在任务标题或其内容中。确认后，整个任务子树先备份到回收区，再从任务文件删除。
- 请先保存相关文件。回收区是人生目录下的普通目录，不是 Windows 系统回收站。
- 目前没有自动恢复命令。手动恢复事件或规划时，还需恢复父级登记，并检查编号冲突及链接；恢复任务时也需检查编号。
- 清空回收区会永久删除全部内容，须输入“清空回收区”确认。请先检查是否仍有需要恢复的项目。

* 测试说明
已在临时目录验证事件和规划的登记格式，以及任务删除和事件归档的基本流程。实际使用前，建议在测试副本中检查新建、删除和手动恢复流程。

* 配置评估与注意事项
- 按功能拆分模块，适合作为当前的个人配置；路径、字体和窗口大小针对现有环境设置，迁移到其他机器时需要检查。
- 缺少软件包时可能访问软件源。首次使用或更换机器前，应确认网络可用并安装所需字体； =elpa/= 被忽略，因此不会随 Git 仓库同步。
- 当前没有自动恢复回收区的命令，也没有完整的自动化回归测试。正式数据应另行备份，并先在测试副本验证操作。
- 新建事件或规划时，如果登记成功后打开文件失败，对象目录和登记仍会保留；可从父级登记表手动打开。
- 显示配置依赖图形窗口和显示器信息；在终端或不同显示环境下尚未充分验证。
